# Emitter

## Description

Controls the infrared projector.

Available modes:

- Off
- Laser
- Always On

## When to Use

Use **Laser** for active stereo.

Use **Off** for passive stereo or stealth mode.

## Modes and scene choice

The emitter can be Off, Laser, or Always On. Laser/active stereo is the normal indoor choice because the dot pattern helps matching. Turn it off for passive stereo, stealth-sensitive work, outdoor use, or scenes where projected IR causes interference or reflection artifacts.
