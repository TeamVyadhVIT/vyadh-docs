# Laser Power

## Description

Adjusts the infrared projector output.

Range:

- 0-360 mW

Higher power increases dot pattern density.

## When to Use

Indoors:

- 150-360

Outdoors:

- Turn off or ignore, as solar infrared reduces its effectiveness.

## Operating range

Laser power controls the projected IR pattern output over a 0–360 range. More projected texture can improve matching on featureless indoor surfaces. The guide suggests 150–360 indoors; sunlight can overwhelm the IR signal, so laser power is generally not useful outdoors.
