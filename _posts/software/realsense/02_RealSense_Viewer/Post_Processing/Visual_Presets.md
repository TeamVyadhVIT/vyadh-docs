# Visual Presets

## Description

Visual Presets are high-level configurations that override the ASIC registers.

Available presets include:

- Dynamic
- High Density
- High Accuracy

## Recommendation

For obstacle avoidance:

- Dynamic
- High Density

## Preset selection

Presets override groups of ASIC registers. The guide lists Dynamic, High Density, and High Accuracy; Dynamic or High Density are suggested starting points for obstacle avoidance. Treat presets as baselines, then document any manual Advanced Mode changes separately.
